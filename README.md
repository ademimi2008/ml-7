# Практические работы № 6 и № 7: машинное обучение

В репозитории два ноутбука Jupyter, выполненные на одном датасете `personality_synthetic_dataset.csv`.

| Работа | Тема | Файл |
|---|---|---|
| № 6 | Классификация текстов (TF-IDF + наивный байесовский классификатор) | `practical_work_6_text_classification.ipynb` |
| № 7 | Случайный лес, сравнение с одиночным деревом, важность признаков | `practical_work_7_random_forest.ipynb` |

## Данные

Файл `personality_synthetic_dataset.csv`:

- 20 000 объектов, 29 числовых признаков (оценки по шкале 0-10, например `social_energy`, `talkativeness`, `empathy`);
- целевая переменная `personality_type`: Extrovert (6857), Ambivert (6573), Introvert (6570);
- пропусков и дубликатов нет;
- датасет синтетический, поэтому выводы относятся к нему, а не к реальным людям.

**Важно для работы № 6.** В датасете нет текстов. Поэтому в ноутбуке каждая строка таблицы переводится в короткий текстовый «самоотчёт» (например, *«Honestly, my talkativeness is very high, about 9 out of 10.»*). Это искусственные тексты, и об этом честно сказано в начале ноутбука.

## Запуск

1. Положите оба `.ipynb` и `personality_synthetic_dataset.csv` в одну папку.
2. Откройте нужный ноутбук (Jupyter, VS Code или Colab).
3. Выполните все ячейки сверху вниз (Run All / Restart and Run All).
4. Впишите свои выводы в ячейки, помеченные «впишите» (там, где нужны ваши комментарии).

Для воспроизводимости везде зафиксирован `random_state=42`.

## Работа № 6. Классификация текстов

Что делает ноутбук:

1. Строит тексты из числовых признаков (с «грязью»: заглавные буквы, пунктуация, цифры, стоп-слова, отрицания, опечатки).
2. Делит данные на train/test **до** векторизации (stratify), чтобы не было утечки данных.
3. Очищает текст: нижний регистр, удаление пунктуации и цифр, удаление стоп-слов. Показывает пример «до / после» по этапам.
4. Токенизирует и применяет стемминг Портера.
5. Векторизует через TF-IDF с `min_df` и `max_df`, выводит размерность матрицы. Сравнивает несколько комбинаций параметров кросс-валидацией на train.
6. Обучает `MultinomialNB`, выводит accuracy, macro-F1, отчёт по классам и матрицу ошибок. Дополнительно сравнивает с логистической регрессией.
7. Разбирает 5 разных ошибок модели с диагностикой для гипотез (сколько слов осталось, что не попало в словарь, какие слова тянули к неверному классу).

Что нужно сделать самостоятельно: написать гипотезу для каждой из 5 ошибок и итоговые выводы.

## Работа № 7. Случайный лес

Что делает ноутбук:

1. Делит данные один раз (train/test, stratify). Все модели обучаются и проверяются на одном и том же разбиении.
2. Сравнивает одиночное дерево и случайный лес с параметрами по умолчанию (accuracy на train и test, разрыв между ними, macro-F1).
3. Обосновывает число деревьев по кривой OOB (out-of-bag) оценки.
4. Подбирает `n_estimators`, `max_depth`, `min_samples_leaf` через `GridSearchCV` (5-кратная стратифицированная кросс-валидация только на train). Дерево настраивается на тех же фолдах.
5. Сравнивает четыре модели: дерево и лес, каждый по умолчанию и настроенный.
6. Строит графики важности признаков: MDI и перестановочная важность на тесте.
7. Проверяет, как меняется качество, если оставлять только топ-k важных признаков, и делает вывод, какие признаки можно исключить.

Ориентиры из пробного запуска (у вас значения могут немного отличаться):

| Модель (параметры по умолчанию) | test macro-F1 |
|---|---|
| Одиночное дерево (глубина 33, 440 листьев) | 0,934 |
| Случайный лес, 100 деревьев (OOB accuracy 0,993) | 0,996 |

По кривой OOB лучшее значение было около 320 деревьев, а плато начинается раньше. Ожидается, что настройка гиперпараметров даст небольшой прирост, потому что лес по умолчанию уже близок к оптимуму. Если так и получится, это нужно честно написать в выводах.

Перебор параметров на обычном компьютере занимает несколько минут. Чтобы ускорить, уменьшите `param_grid` в разделе 4.2.

## Чего нельзя делать

- Подбирать параметры или отбирать признаки по тестовой выборке.
- Обучать векторизатор (работа № 6) на всём датасете, это утечка данных.
- Сравнивать дерево и лес на разных разбиениях.
- Оставлять лес по умолчанию без объяснения, почему настройка не потребовалась.
- Интерпретировать важность признаков как причинно-следственную связь: это ассоциация в синтетических данных.
- Сдавать ноутбук с пустыми выводами или с ошибками в ячейках.
